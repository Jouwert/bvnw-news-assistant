# Editorial run example

This artifact shows the shape of the BVNW run archive without copying private editorial material directly.

## Shortlist example
A shortlist file typically captures:
- the date of the run;
- shortlist-only status;
- a small number of candidate items;
- why each candidate may matter for Noordwest or the Binnenveld;
- direct source links;
- brief notes on why some items were not shortlisted.

Example shape:

```md
# BVNW news assistant — candidate shortlist

_Date run:_ 2026-04-XX
_Status:_ shortlist only

## 1. Local landscape item
- Source: local public site
- Direct link: https://example.org/item-1
- Why it may matter: direct relevance for Noordwest/Binnenveld readers

## 2. Neighbourhood activity item
- Source: local public site
- Direct link: https://example.org/item-2
- Why it may matter: concrete local usefulness

## Items seen but not shortlisted
- city-wide item with no clear Noordwest angle
- older item with weak timing
```

## Final-post example
A final-draft file typically keeps a copyable WhatsApp-ready post in one fenced block.

Example shape:

```md
> *Voorbeeldtitel buurtbericht*
> _noordwest nieuws_
>
> Korte posttekst in één doorlopend blok, geschreven voor makkelijk copy/paste gebruik.
>
> _Bron: publieke bron | Gemaakt met AI_
```

## Why this artifact matters
The interesting part is not just the generated text.
It is the fact that the project keeps:
- shortlist reasoning;
- selection context;
- final-post format;
- source attribution;
- durable files on disk.

That makes the editorial workflow inspectable instead of disposable.
